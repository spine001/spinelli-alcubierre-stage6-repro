# Historical recovery: Spinelli Framework Stages 1-5

These files were generated on June 8-10, 2026 during the 32 GB Windows laptop
phase of the Alcubierre validation project. They were not under Git at that
time. This directory was assembled later to recover their provenance without
fabricating an earlier Git history.

Source formats:
- Stages 1-3: self-contained HTML calculation/article lineage.
- Stages 4A-4D: Visual Studio Code Jupyter notebooks plus CSV/JSON/ZIP outputs.
- Stages 5A-5B: Visual Studio Code Jupyter notebook plus CSV/JSON/ZIP outputs.

Authority rules:
- The executed DIM=4 memory-optimized Stage 4 notebook is authoritative.
- The earlier unexecuted Stage 4 notebook is retained as a design predecessor.
- The nonempty Stage 5 notebook under Stage 5 test is authoritative.
- The zero-byte Stage 5 notebook placeholder under Stage 4C test is excluded.
- The later Stage 4A-C export is canonical; the earlier repeated export is
  retained only as provenance because numerical files are identical.
- Original timestamps and SHA-256 hashes are recorded in provenance_manifest.csv.
